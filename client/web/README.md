# 龙生九子 Web客户端

这是一个简单的网页版游戏客户端，用于连接和测试龙生九子游戏服务器。

## 功能特性

- 🎮 完整的游戏流程：登录、房间管理、游戏对战
- 🎨 五行元素可视化：不同颜色表示不同元素区域
- ⚔️ 战斗系统：点击攻击、技能释放（Q/W/E/R）
- 🎒 物品系统：道具拾取和使用（1/2/3键）
- 💬 实时聊天
- 👁️ 观战模式
- 📊 排行榜系统

## 快速开始

### 1. 启动游戏服务器

首先确保游戏服务器正在运行：

```bash
cd /workspace/server
npm install
npm start
```

服务器将在 `ws://localhost:8080` 上运行。

### 2. 启动Web客户端

有两种方式运行客户端：

#### 方式一：使用Python简单HTTP服务器

```bash
cd /workspace/client/web
python3 -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`

#### 方式二：使用Node.js的http-server

```bash
npm install -g http-server
cd /workspace/client/web
http-server -p 8000
```

#### 方式三：直接打开HTML文件

如果只是本地测试，也可以直接在浏览器中打开 `index.html` 文件。

## 游戏操作

### 移动
- **W/A/S/D** 或 **方向键**：控制角色移动

### 战斗
- **鼠标左键**：普通攻击
- **Q/W/E/R**：释放技能（自动锁定最近的敌人）
- **1/2/3**：使用背包中的道具

### 其他
- **Enter**：发送聊天消息

## 游戏流程

1. **登录**：输入用户名进入游戏大厅
2. **选择房间**：
   - 创建新房间
   - 加入已有房间
   - 快速匹配
   - 观战进行中的游戏
3. **游戏对战**：
   - 收集同元素水果提升攻击力
   - 收集其他元素水果提升其他属性
   - 拾取道具获得临时增益
   - 击败对手成为最后的幸存者
4. **游戏结束**：查看战斗统计和排行榜

## 技术实现

- 纯原生 JavaScript，无需构建工具
- Canvas 2D渲染
- WebSocket 实时通信
- 响应式UI设计
