# 龙生九子·五行对战 - Web客户端

## 概述

这是《龙生九子·五行对战》游戏的HTML5 Web客户端，提供完整的游戏体验，包括实时多人对战、技能特效、音效系统等。

## 功能特色

### 🎮 核心游戏功能
- **实时多人对战** - WebSocket连接，20Hz同步
- **五行角色系统** - 9个龙生九子角色选择
- **技能系统** - 50+技能，支持主动/被动技能
- **道具系统** - 背包管理，道具使用
- **排行榜** - 实时击杀和存活排名

### 🎨 视觉系统
- **Canvas渲染** - HTML5 Canvas 2D渲染引擎
- **粒子特效** - 40+技能特效配置
- **屏幕效果** - 震动、闪光、视觉反馈
- **UI界面** - 现代化游戏UI设计
- **小地图** - 实时战况显示

### 🔊 音效系统
- **Web Audio API** - 高质量音效播放
- **技能音效** - 每个技能独特的音效
- **UI音效** - 按钮点击、通知音效
- **音量控制** - 独立的音效/音乐音量调节

### ⌨️ 输入系统
- **键盘控制** - WASD移动，QWER技能，123道具
- **鼠标控制** - 点击移动，右键技能
- **键位自定义** - 支持自定义键位绑定
- **聊天系统** - Enter键聊天

## 使用方法

### 本地开发

1. **启动服务器**:
```bash
cd ../server
npm install
npm start
```

2. **启动客户端**:
```bash
cd client
# 使用任意HTTP服务器，例如：
python -m http.server 8080
# 或者
npx serve .
```

3. **访问游戏**: 打开浏览器访问 `http://localhost:8080`

### 生产部署

客户端是纯静态文件，可以部署到任何Web服务器：
- Nginx
- Apache
- CDN (如CloudFlare)
- 静态托管服务 (如Netlify, Vercel)

## 操作说明

### 基础操作
- **移动**: WASD 或 方向键
- **攻击**: 左键点击敌人
- **技能**: Q/W/E/R 或 右键点击敌人
- **道具**: 1/2/3 数字键

### UI操作
- **排行榜**: Tab键 或 点击排行榜按钮
- **聊天**: Enter键 或 点击聊天按钮
- **设置**: 主菜单设置按钮
- **暂停**: Esc键

### 技能系统
- 每个角色随机获得4个技能
- 技能有冷却时间，UI会显示剩余时间
- 不同元素的技能在对应区域有加成
- 被动技能自动生效

### 道具系统
- 拾取地面道具自动进入背包
- 拖拽道具到快捷栏使用
- 数字键快速使用道具

## 技术特色

### 性能优化
- **Canvas优化** - 设备像素比适配
- **粒子池** - 重用粒子对象减少GC
- **质量等级** - 根据设备性能调整特效质量
- **帧率监控** - 实时FPS显示

### 网络优化
- **断线重连** - 自动重连机制
- **消息缓存** - 离线时缓存消息
- **延迟显示** - 实时网络延迟监控
- **输入节流** - 避免过度发送输入消息

### 用户体验
- **响应式设计** - 适配不同屏幕尺寸
- **无障碍支持** - 键盘导航支持
- **设置持久化** - 用户设置本地保存
- **错误恢复** - 优雅的错误处理

## 配置选项

### 图形设置
- **画面质量**: 低/中/高 (影响粒子数量)
- **特效开关**: 开启/关闭粒子特效
- **屏幕效果**: 震动、闪光效果开关

### 音频设置
- **主音量**: 整体音量控制
- **音效音量**: 技能和UI音效音量
- **音乐音量**: 背景音乐音量

### 控制设置
- **键位绑定**: 自定义按键设置
- **鼠标灵敏度**: 鼠标操作灵敏度
- **右键技能**: 右键释放技能开关
