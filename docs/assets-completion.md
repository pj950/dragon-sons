## 🚀 使用方法

### 🎯 快速生成资源

1. **打开资源生成工具**:
   ```bash
   cd client
   npx serve . -p 8080
   # 访问: http://localhost:8080/generate-assets.html
   ```

2. **一键生成所有资源**:
   - 点击"生成所有资源"按钮
   - 等待生成完成 (约1-2分钟)
   - 点击"下载完整资源包"

3. **部署到游戏**:
   - 将下载的文件放置到 `assets/` 对应目录
   - 游戏自动加载和使用资源

### 🔧 开发者工具

**命令行工具**:
```bash
npm run generate-assets  # 创建资源目录结构
npm run deploy-assets    # 部署资源清单
```

**浏览器工具**:
- `generate-assets.html` - 可视化资源生成工具
- `test.html` - 客户端功能测试工具
