## 🚀 使用方法

### 🏃‍♂️ 快速开始

1. **启动服务器**:
```bash
cd server
npm install
npm start
```

2. **启动客户端**:
```bash
cd client  
npx serve . -p 8080
```

3. **打开游戏**: 访问 `http://localhost:8080`

4. **测试功能**: 访问 `http://localhost:8080/test.html`

### 🎯 游戏操作

**基础操作**:
- **移动**: WASD 或 方向键
- **攻击**: 左键点击敌人  
- **技能**: Q/W/E/R 或 右键点击敌人
- **道具**: 1/2/3 数字键

**UI操作**:
- **排行榜**: Tab键
- **聊天**: Enter键
- **设置**: 主菜单设置按钮
- **暂停**: Esc键
