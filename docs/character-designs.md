# 龙生九子角色视觉设计

## 🐉 九子角色设计理念

基于中国传统神话中的龙生九子，每个角色都有独特的外观特征、性格特点和战斗风格，体现五行元素的力量。

## 🎨 角色视觉设计

### 1. 囚牛 (Qiuniu) - 音律之龙
**属性**: 攻100 敏95 闪12% 防90 暴10% 爆1.50  
**定位**: 均衡型，闪避偏高  
**元素倾向**: 金/木 (音律共鸣)

**视觉设计**:
- **主色调**: 金黄色 (#FFD700) 配 翠绿色 (#32CD32)
- **外观特征**: 
  - 龙首温和，眼神专注
  - 身披音符纹样的鳞甲
  - 角上盘绕着音波光环
  - 爪子精巧，适合弹奏
- **符号**: 🎵 (音符)
- **特效色彩**: 金绿交融的音波涟漪
- **性格**: 沉稳、艺术气质、平衡感强

## 🖼️ 角色头像生成

### 头像设计规范
- **尺寸**: 128x128 像素
- **风格**: 中国传统 + 现代游戏风格
- **色彩**: 五行元素主题配色
- **特征**: 突出每个角色的独特性格

### 头像生成代码
```javascript
// 角色头像生成器
class CharacterAvatarGenerator {
    generateAvatar(characterId, size = 128) {
        const canvas = document.createElement('canvas');
        canvas.width = size;
        canvas.height = size;
        const ctx = canvas.getContext('2d');
        
        const style = CHARACTER_STYLES[characterId];
        if (!style) return null;
        
        // 背景圆形渐变
        const gradient = ctx.createRadialGradient(
            size/2, size/2, 0,
            size/2, size/2, size/2
        );
        gradient.addColorStop(0, style.bodyColor);
        gradient.addColorStop(0.7, style.accentColor);
        gradient.addColorStop(1, ColorUtils.addAlpha(style.bodyColor, 0.8));
        
        ctx.fillStyle = gradient;
        ctx.beginPath();
        ctx.arc(size/2, size/2, size/2 - 4, 0, Math.PI * 2);
        ctx.fill();
        
        // 角色符号
        ctx.fillStyle = '#FFFFFF';
        ctx.font = `bold ${size * 0.3}px Arial`;
        ctx.textAlign = 'center';
        ctx.textBaseline = 'middle';
        ctx.shadowColor = 'rgba(0,0,0,0.5)';
        ctx.shadowBlur = 4;
        ctx.fillText(style.symbol, size/2, size/2 - size * 0.05);
        
        // 角色名称
        ctx.font = `bold ${size * 0.12}px Arial`;
        ctx.fillText(this.getCharacterName(characterId), size/2, size/2 + size * 0.25);
        
        // 清除阴影
        ctx.shadowColor = 'transparent';
        ctx.shadowBlur = 0;
        
        // 装饰边框
        ctx.strokeStyle = style.accentColor;
        ctx.lineWidth = 4;
        ctx.beginPath();
        ctx.arc(size/2, size/2, size/2 - 2, 0, Math.PI * 2);
        ctx.stroke();
        
        return canvas.toDataURL();
    }
    
    getCharacterName(characterId) {
        const names = {
            qiuniu: '囚牛',
            yazi: '睚眦', 
            chaofeng: '嘲风',
            pulao: '蒲牢',
            suanni: '狻猊',
            bixi: '赑屃',
            bixie: '狴犴',
            fuxi: '负屃',
            chiwen: '蚩吻'
        };
        return names[characterId] || '未知';
    }
}
```

## 🎮 游戏内角色渲染

### 角色在游戏中的视觉表现

#### 基础渲染
```javascript
// 在renderer.js中的角色渲染
renderPlayer(player) {
    const style = CHARACTER_STYLES[player.characterId] || CHARACTER_STYLES.qiuniu;
    const radius = 1.5 * style.size;
    
    // 主体
    this.ctx.beginPath();
    this.ctx.arc(player.x, player.y, radius, 0, Math.PI * 2);
    this.ctx.fillStyle = style.bodyColor;
    this.ctx.fill();
    
    // 装饰圆环
    this.ctx.strokeStyle = style.accentColor;
    this.ctx.lineWidth = 0.2;
    this.ctx.stroke();
    
    // 角色符号
    this.ctx.fillStyle = '#FFFFFF';
    this.ctx.font = 'bold 0.8px Arial';
    this.ctx.fillText(style.symbol, player.x, player.y);
    
    // 特殊效果
    this.renderCharacterSpecialEffect(player, style);
}

// 角色特殊效果
renderCharacterSpecialEffect(player, style) {
    const time = Date.now() * 0.001;
    
    switch (style.specialEffect) {
        case 'musical_notes':
            // 囚牛 - 音符飘动
            this.renderFloatingNotes(player.x, player.y, time);
            break;
        case 'blade_aura':
            // 睚眦 - 刀刃光环
            this.renderBladeAura(player.x, player.y, time);
            break;
        case 'wind_trail':
            // 嘲风 - 风迹
            this.renderWindTrail(player.x, player.y, time);
            break;
        // ... 其他角色特效
    }
}
```

#### 角色选择界面
```javascript
// 角色选择UI
class CharacterSelectUI {
    renderCharacterGrid() {
        const characters = Object.keys(CHARACTER_STYLES);
        const grid = document.getElementById('characterGrid');
        
        characters.forEach(characterId => {
            const card = this.createCharacterCard(characterId);
            grid.appendChild(card);
        });
    }
    
    createCharacterCard(characterId) {
        const style = CHARACTER_STYLES[characterId];
        const card = document.createElement('div');
        card.className = `character-card character-${characterId}`;
        
        card.innerHTML = `
            <div class="character-avatar">
                <div class="character-symbol">${style.symbol}</div>
            </div>
            <div class="character-name">${this.getCharacterName(characterId)}</div>
            <div class="character-stats">
                <div class="stat">攻击: ${this.getCharacterStat(characterId, 'atk')}</div>
                <div class="stat">敏捷: ${this.getCharacterStat(characterId, 'agi')}</div>
                <div class="stat">防御: ${this.getCharacterStat(characterId, 'def')}</div>
            </div>
        `;
        
        return card;
    }
}
```

## 📊 角色平衡设计

### 角色定位明确
```
坦克型: 赑屃 (防120) > 狴犴 (防105) > 狻猊 (防100)
敏捷型: 蒲牢 (敏115) > 嘲风/负屃 (敏110) > 蚩吻 (敏100)
输出型: 睚眦 (攻115) > 蒲牢/蚩吻 (攻105) > 狻猊/囚牛/狴犴 (攻100)
闪避型: 负屃 (闪15%) > 嘲风 (闪14%) > 囚牛 (闪12%)
暴击型: 睚眦 (暴14%) > 狻猊/蚩吻 (暴12%) > 嘲风/蒲牢 (暴11%)
```
